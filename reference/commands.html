Quick reference for all Makefile commands. For full syntax, flags, and example output, use the per-command pages under Commands.

Test commands: Run make test for the full suite. Use make test-watch for watch mode, make test-coverage for coverage, and make test-brands for E2E both brands. Use make fresh-install for a full reset (deps + dev-env) then E2E. To run a subset by path: npx vitest run tests/domain or npx vitest run tests/cli.

Approval guards: When data has already been built or synced and you run make build or make push again, the tool shows what changed (copy, destinations, items added/removed) and asks for approval instead of blocking. Use FORCE=1 to skip the prompt (e.g., in CI). Use YES=1 to auto-approve.

build-all / push-all: For CI or batch runs. Run make pull first; then make build-all builds all dates; then make push-all syncs all of them to SFCC. Use YES=1 to skip confirmation prompts. Use FAIL_FAST=1 to stop on first failure (default: continue on error).

Automation: For scripts and CI, use DATE=, REFRESH=, YES=1, FORCE=1 as needed. Use VERBOSE=1 for run IDs on log lines. Use FAIL_FAST=1 for fail-fast batch runs, and ARGS="..." to pass extra CLI flags.

Make variables → CLI flags ​

The Makefile is the source of truth. All commands are invoked via make <target>; the CLI receives variables as flags.

Make variableCLI flag / behaviourExample
BRANDFirst positional arg after commandmake build → node … refresh loft
DATE--date=YYYY-MM-DDmake build DATE=2026-02-14
REFRESH--refresh=r1make push REFRESH=r2
FORCE=1--forcemake build FORCE=1
YES=1--yes (skip confirmation/approval prompts)make push-all YES=1
ALL=1build/push: --all-refreshes (all refreshes in a date); status: --show-all (full history)make status ALL=1
FAIL_FAST=1Stop build-all/push-all on first failure (default: continue)make build-all FAIL_FAST=1
ARGS="..."Pass extra CLI flags (appended after mapped vars)make push ARGS="--yes --force"

CONVERT=1--convertmake pull CONVERT=1

STATUS_ACTION_INDEXstatus (non-TTY): 0-based index of action (0=preview, 1=push, 2=commit, 3=edit, 4=email, 5=validate, 6=pull)STATUS_ACTION_INDEX=1 make status

Source & OCAPI: Use make setup to switch data source (local/Smartsheet) and enable/disable SFCC sync. The setup wizard handles brand, source, and OCAPI configuration.
