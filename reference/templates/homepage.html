{{!-- Example Zone Template for Developers ===================================== This file
demonstrates how to use Handlebars in zone templates. Copy this file and rename it to match your
zone (e.g., hp_hero.html). Available Context Variables: ---------------------------- - zoneKey: The
zone identifier (e.g., "HP_HERO") - assetType: The asset type (e.g., "HOMEPAGE") - items: Array of
zone items from the JSON data - brand: Brand name - refreshDate: Refresh date (YYYY-MM-DD) -
refreshId: Refresh ID (e.g., "r1") Flattened First Item (for single-item zones):
---------------------------------------------- For convenience, the first item's properties are
flattened into context: - copy: First item's copy (use {{copy}} instead of {{items.[0].copy}}) -
destination: First item's destination object - altText: First item's alt text - order, action,
notes, device, siteLocation Each item in items[] contains: - order: Item order number - action:
Action type (LAUNCH, UPDATE, NO_CHANGE, etc.) - copy: Text content (may contain HTML) - destination:
{ type, id, ipid } - altText: Alt text for images URL Helpers: ------------ {{sfccUrl destination.id
destination.ipid}} - Outputs SFCC $url()$ syntax for server-side URL generation - Example:
$url('Search-Show','cgid','catl00009','ipid','...')$ - Supports extra params: {{sfccUrl catId ipid
"prefn1" "size"}} {{assetUrl destination ipid}} - Simple URL format: /catId?ipid=... - Use for
non-SFCC contexts Promo Helper: ------------- {{extractPromo destination.ipid}} - Extracts promo
code from IPID (e.g., "EP60" from the IPID) - Returns empty string if no promo or "np" Other
Helpers: -------------- {{formatDate date "MM/DD/YY"}} - Format dates {{upper text}} - Uppercase
text {{lower text}} - Lowercase text {{default value "fallback"}} - Default value if empty {{eq a
b}} - Equality check {{#if condition}}...{{/if}} - Conditional blocks {{#each items}}...{{/each}} -
Loop over arrays {{{htmlContent}}} - Output raw HTML (triple braces) IPID Helper (for custom IPIDs):
{{ipid brand page device zone position promo destination date}} SFCC URL Examples:
------------------ Single destination:
<a href="{{sfccUrl destination.id destination.ipid}}">Shop Now</a>
Output: <a href="$url('Search-Show','cgid','catl00009','ipid','loft_hp_...')$">Shop Now</a>

With filtering params:
<a href="{{sfccUrl destination.id destination.ipid 'prefn1' 'size' 'prefv1' 'small'}}">
  Output: $url('Search-Show','cgid','catl00009','ipid','...','prefn1','size','prefv1','small')$ --}}

  <!-- Example Zone: {{zoneKey}} -->
  <section class="zone-example" data-zone="{{zoneKey}}">
    {{!-- Loop through items --}} {{#each items}}
    <div class="zone-item" data-order="{{order}}">
      {{!-- Output copy with HTML preserved --}}
      <div class="item-content">{{{copy}}}</div>

      {{!-- Add CTA link if destination exists --}} {{#if destination}}
      <a
        href="{{sfccUrl destination.id destination.ipid}}"
        class="item-cta"
        data-way-finding="homepage:{{lower ../zoneKey}}"
      >
        Shop Now
      </a>
      {{/if}}
    </div>
    {{/each}}
  </section>

  <style>
    /* Zone-specific styles go here */
    .zone-example {
      padding: 20px 0;
    }

    .zone-item {
      margin-bottom: 15px;
    }

    .item-cta {
      display: inline-block;
      padding: 10px 20px;
      background: #000;
      color: #fff;
      text-decoration: none;
    }
  </style>
