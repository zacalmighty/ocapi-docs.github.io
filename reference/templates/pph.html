PPH ​

Promo page header with rotating slides

Template Source ​

html
{{!-- PPH - Promo Page Header Template --}} {{!-- Auto-generated from JSON data. Each item becomes a
rotating slide. --}} {{!-- JSON fields: copy, destination.id, destination.ipid, action --}}

<div class="text-slide">
  {{#each items}} {{#unless (eq action "REMOVE")}}
  <div>
    {{stripCta copy}}&nbsp; {{#if destination}}
    <a data-way-finding="homepage:pph" href="{{sfccUrl destination.id destination.ipid}}"
      >Shop Now></a
    >
    {{/if}}
    <button class="global-promo-modal-btn" link="" type="button">
      <!--See Details-->
    </button>
  </div>
  {{/unless}} {{/each}}
</div>

Usage ​

This template is resolved via resolveTemplate(assetType) in src/config/slots.config.js.

javascript
const { resolveTemplate } = require('./config/slots.config');
const template = resolveTemplate('PPH');
// Returns: "pph/template"
