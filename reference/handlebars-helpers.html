Handlebars Helpers Reference ​

Complete reference for all custom Handlebars helpers available in templates.

Interactive Playground ​

Examples:
  <div>Hello</div>
  <div>World</div>

SFCC URL Helpers ​

These helpers generate Demandware URL syntax for SFCC.

sfccUrl ​

Generates a category URL with optional tracking.

Signature: {{sfccUrl categoryId [ipid] [param1] [value1] ...}}

handlebars
<a href="{{sfccUrl 'cat3950014' 'loft_hp_hero_newarrivals'}}">Shop Now</a>
1
html
<a href="$url('Search-Show','cgid','cat3950014','ipid','loft_hp_hero_newarrivals')$">Shop Now</a>
1

With extra parameters:

handlebars
{{sfccUrl "cat123" "tracking_id" "srule" "best-sellers"}}
1
html
$url('Search-Show','cgid','cat123','ipid','tracking_id','srule','best-sellers')$
1

assetUrl ​

Generates a safe URL with optional IPID tracking. Sanitizes dangerous URLs.

Signature: {{assetUrl destination [ipid]}}

handlebars
<a href="{{assetUrl destination.id destination.ipid}}">{{destination.copy}}</a>
1
html
<a href="/sale?ipid=loft_hp_hero_sale">Shop Sale</a>
1

Security: Blocks javascript:, data:, and vbscript: URLs.

ipid ​

Generates a tracking ID from components.

Signature: {{ipid brand page device zone position promo destination date}}

handlebars
{{ipid "loft" "hp" "all" "hero" "a" "FP50" "clothingviewall" "2026-01-26"}}
1
html
loft_hp_all_hero_a_fp50_clothingviewall_012626
1

Use these patterns with the sfccUrl helper or in raw HTML:

TypeDemandware URLDescription
Category$url('Search-Show','cgid','12345')$Links to category page
Product$url('Product-Show','pid','12345')$Links to product page
Product + Color$url('Product-Show','pid','12345','dwvar_12345_color','0894')$Product with variant
Category + Sort$url('Search-Show','cgid','12345','srule','sortingrule-id')$Category with sorting
Category + Filter$url('Search-Show','cgid','12345','prefn1','filterID','prefv1','filterValue')$Category with filter
Content Asset$url('Page-Show','cid','12345')$Links to content page
Search$url('Search-Show','q','term')$Search results
Pipeline$url('Pipeline-Name')$Direct pipeline URL
Secure Pipeline$httpsURL('Pipeline-Name')$HTTPS pipeline URL

stripCta ​

Removes trailing CTA text like "Shop Now>" from marketing copy.

Signature: {{stripCta text}}

Removes: Shop Now>, Shop Sale>, Shop All>, Shop It>

HTML Helpers ​

html ​

Render raw HTML with XSS sanitization. Strips dangerous elements while preserving safe formatting.

handlebars
{{{html trustedHtmlContent}}}
1
html
<strong>Bold text</strong> and <em>italic</em>
1

Sanitizes out:

  • <script>, <style>, <noscript> tags
  • Event handlers (onclick, onerror, etc.)
  • javascript:, data:, vbscript: URLs
  • <iframe>, <object>, <embed>, <applet> tags
  • <form>, <base>, <meta http-equiv="refresh"> tags
  • CSS expressions (expression(), -moz-binding, behavior:url())

safeCopy ​

Sanitize copy content for safe triple-stash rendering. Same sanitization as html; preferred when rendering copy fields explicitly.

handlebars
{{{safeCopy copy}}}
1
html
40% off your purchase<sup>*</sup>
1

Copy field security

All copy fields from Excel/Smartsheet are automatically sanitized in the template context before rendering. This means {{{copy}}} is safe — dangerous elements (script, iframe, event handlers) are stripped while formatting HTML (br, sup, span, etc.) is preserved. The safeCopy and html helpers are available for explicit sanitization of other fields.

extractPromo ​

Extract promo code from an IPID string.

handlebars
{{extractPromo "loft_hp_all_hero_a_FP50_clothing_012626"}}
1

Output: FP50

json ​

Output data as JSON (for debugging).

handlebars

log ​

handlebars
