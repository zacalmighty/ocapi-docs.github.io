GenerateDevFiles - Generate dev environment files from Refresh data. ​

GenerateDevFiles - Generate dev environment files from Refresh data.

GenerateDevFiles orchestrates the generation of dev environment files from Refresh DTOs or existing Campaign entities.

Group: application

Methods ​

execute(target, options, options.forceRefresh, options.skipRemote, options.dryRun, options.merge, options.skipValidation) ​

Generate dev environment files from a Refresh DTO, Campaign entity, asset array, or campaign-ID string. Compiles the target into a Campaign, renders HTML for each asset, writes files to disk, generates an OCAPI payload, and optionally triggers ComposePreview for multi-zone composition.

ParameterTypeDescription
target`Campaignobject
optionsobjectGeneration options.
options.forceRefreshbooleanForce-regenerate even if HTML exists.
options.skipRemotebooleanSkip fetching HTML from OCAPI.
options.dryRunbooleanReport what would happen without writing.
options.mergebooleanMerge with existing JSON data.
options.skipValidationbooleanBypass refresh validation.

Returns: Promise&lt;object&gt; — executeWrapped result containing config + results.

_compileTargetToCampaign(target, opts) ​

Resolve the target argument into a Campaign, assets, metadata, and summaries. Handles Refresh DTOs, Campaign entities, asset arrays, and string IDs.

ParameterTypeDescription
target`objectArray
optsobjectMerged options from execute().

Returns: Promise&lt;{campaign: (object|null), assets: Array, refreshMeta: (object|null), actionSummary: (object|null), reuseSummary: (object|null)}&gt;

_renderOutput(campaign, refreshMeta, actionSummary, reuseSummary, buildResult, assets, opts) ​

Render a dashboard summary of the build results via the output port.

ParameterTypeDescription
campaign`objectnull`
refreshMeta`objectnull`
actionSummary`objectnull`
reuseSummary`objectnull`
buildResultobjectResult from _buildDevFiles ({ updatedAssets, skippedAssets }).
assetsArrayFull asset list.
optsobjectGeneration options.

generateOcapiPayload(campaign, refreshMeta, refreshMeta.refreshDate, refreshMeta.refreshId, refreshMeta.refreshKey) ​

Build and persist the OCAPI payload JSON for a compiled Campaign. Delegates building to OcapiPayloadBuilder and saving to FileSystemStore.

ParameterTypeDescription
campaignCampaignCompiled Campaign entity.
refreshMetaobjectRefresh metadata from CompileRefresh.extractRefreshMeta.
refreshMeta.refreshDatestringRefresh date (YYYY-MM-DD).
refreshMeta.refreshIdstringRefresh ID (e.g. "r1").
refreshMeta.refreshKeystringAlternative key used as refreshId fallback.

_buildDevFiles(assets, options) ​

Write HTML files for each asset to the dev-env directory. Handles reuse skipping, inactive asset filtering, DEVELOPER-mode preservation, OCAPI fallback, and template rendering.

ParameterTypeDescription
assetsArrayAsset objects or ID strings.
optionsobjectMerged options from execute().

Returns: Promise&lt;{updatedAssets: Array&lt;string&gt;, skippedAssets: Array&lt;string&gt;}&gt;

_prependDataContext(html, asset, assetId, assetType) ​

Prepend a Handlebars comment block with data-context metadata to the HTML. Skips if the HTML already contains a @data-source annotation.

ParameterTypeDescription
htmlstringRendered HTML content.
assetobjectAsset object with _zoneData.
assetIdstringAsset identifier.
assetTypestringResolved asset type key.

Returns: string — HTML with prepended data-context comment.

_extractAssetTypeFromId(assetId) ​

Extract and resolve the asset type key from a compound asset ID string.

ParameterTypeDescription
assetIdstringAsset identifier (e.g. "loft-2026-01-26-r1-homepage-hp_hero").

Returns: string | null — Resolved asset type key (e.g. "HOMEPAGE") or null.

getAssetsByPrefix(prefix) ​

Search the dev-env file system for assets matching a prefix string.

ParameterTypeDescription
prefixstringAsset ID prefix to search for (e.g. "loft-2026-01-26").

Returns: Promise&lt;Array&lt;string&gt;&gt; — Matching asset IDs.
