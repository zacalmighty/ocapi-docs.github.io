CompileRefresh transforms Refresh DTOs into Campaign domain models. ​

CompileRefresh transforms Refresh DTOs into Campaign domain models.

Architectural Note ​

CompileRefresh is a Domain Service, not a Use Case. It does not extend BaseUseCase because:

  • It performs pure synchronous transformation (DTO → Domain Entity)
  • It has no external I/O (no API calls, no async file operations)
  • It doesn't need executeWrapped infrastructure (metrics, retries, error recovery)
  • It is called by use cases (ExcelWorkflow, DevWorkflow) as a helper service

Asset Reuse Logic ​

  • LAUNCH: Create new asset ID, register in AssetRegistry
  • NO_CHANGE: Look up existing asset ID from registry, reuse it
  • UPDATE: Use existing asset ID, update content
  • REMOVE: Unregister from AssetRegistry

execute(refresh, options, options.skipValidation) ​

Compile a Refresh DTO into a Campaign domain model. Validates the refresh (unless skipValidation is set), builds slots with resolved asset IDs and IPIDs, and returns a Campaign entity.

ParameterTypeDescription
refreshRefreshDTOParsed refresh DTO with campaign metadata and assetsByType.
optionsobjectCompile options.
options.skipValidationbooleanSkip Zod schema validation.

Returns: Campaign — Compiled Campaign domain entity.

_buildSlots(refresh, options) ​

Build all slot objects from a Refresh DTO by iterating asset types and zones.

ParameterTypeDescription
refreshRefreshDTOParsed refresh DTO.
optionsobjectCompile options forwarded to _createZoneSlot.

Returns: Array&lt;object&gt; — Array of slot configuration objects.

_createZoneSlot(params, params.refresh, params.assetTypeKey, params.zoneKey, params.zoneData, params.hasMultipleZones, params.options) ​

Create a single slot object for one asset-type/zone combination. Resolves asset ID (new or reused), builds IPIDs, and assembles the full slot descriptor with context, sync strategy, and category IDs.

ParameterTypeDescription
paramsobjectZone slot creation parameters.
params.refreshRefreshDTOParent refresh DTO.
params.assetTypeKeystringAsset type key (e.g. "HOMEPAGE").
params.zoneKeystringZone key (e.g. "ZONE_A").
params.zoneDataobjectZone object containing items array.
params.hasMultipleZonesbooleanWhether the asset type has multiple zones.
params.optionsobjectCompile options.

Returns: object — Slot configuration object ready for Campaign.fromJSON.

_assetTypeToPage(assetTypeKey) ​

Map an asset type key to a short page identifier for IPID construction. Falls back to a slugified, lowercased, 8-char truncation of the key.

ParameterTypeDescription
assetTypeKeystringAsset type key (e.g. "HOMEPAGE", "PPH").

Returns: string — Short page code (e.g. "hp", "pph", "global").

_buildIpidForItem(item, index, refresh, assetTypeKey, zoneKey) ​

Build an IPID (Internal Promotion ID) string for a single line item. Combines brand, page, device, zone, position, promo copy, destination, and date into a standardized tracking identifier.

ParameterTypeDescription
itemobjectLine item from the Excel zone data.
indexnumberZero-based position within the zone.
refreshRefreshDTOParent refresh DTO (used for date fallback).
assetTypeKeystringAsset type key (e.g. "HOMEPAGE").
zoneKeystringZone key (e.g. "ZONE_A").

Returns: string — Constructed IPID string.

_getDominantAction(items) ​

Determine the dominant action for a set of zone items. Priority order: LAUNCH > UPDATE > REMOVE > NO_CHANGE. Returns NO_CHANGE when items is empty or all items are NO_CHANGE.

ParameterTypeDescription
itemsArray&lt;object&gt;Zone line items, each with an action field.

Returns: string — The dominant ACTION_TYPE constant.

_resolveAssetId(params, params.refresh, params.assetTypeKey, params.zoneKey, params.hasMultipleZones, params.action) ​

Resolve the asset ID for a slot, deciding whether to reuse an existing registry entry or create a new one. Handles NO_CHANGE→LAUNCH bootstrap when no registry entry exists for an unchanged asset.

ParameterTypeDescription
paramsobjectAsset ID resolution parameters.
params.refreshRefreshDTOParent refresh DTO.
params.assetTypeKeystringAsset type key.
params.zoneKeystringZone key.
params.hasMultipleZonesbooleanWhether zone suffix is needed in ID.
params.actionstringRaw action from the dominant-action check.

Returns: Object

_createCampaignId(refresh) ​

ParameterTypeDescription

_createAssetId(params, params.refresh, params.assetTypeKey, params.zoneKey, params.hasMultipleZones) ​

Build a deterministic content-asset ID from brand, date, refresh ID, asset type, and optionally zone key. Multi-zone assets include a zone suffix; single-zone assets omit it.

ParameterTypeDescription

Resolve the SFCC slot ID for an asset type and zone. Checks slot config first, then falls back to brand-level slot mappings, and finally the raw zone key.

extractRefreshMeta(refresh) ​

Extract canonical refresh metadata from a Refresh DTO. Used by callers that need date/id/brand without compiling a full Campaign.

ParameterTypeDescription
refreshRefreshDTORefresh DTO.

Returns: Object

registerAssets(campaign, refresh) ​

Register, unregister, or touch assets in the in-memory AssetRegistry based on the effective actions computed during compilation.

  • LAUNCH (not reused): register the new asset with its items/IPIDs.
  • REMOVE: unregister the asset type + zone from the registry.
  • UPDATE: touch the entry (update lastUpdated timestamp). Only updates in-memory state; the caller (e.g. GenerateDevFiles) is responsible for calling assetRegistry.save() when appropriate.
ParameterTypeDescription
campaignCampaignCompiled Campaign entity.
refreshRefreshDTOOriginal refresh DTO (used for date/id metadata).

getReuseSummary(campaign) ​

Compute a summary of asset reuse for a compiled Campaign. Categorizes each asset as new, reused, or bootstrapped (NO_CHANGE→LAUNCH fallback).

ParameterTypeDescription
campaignCampaignCompiled Campaign entity.

Returns: Object
