domain/entities/SlotConfiguration ​

SlotConfiguration Domain Entity

SlotConfiguration links a ContentAsset to a specific page slot within a Campaign. It defines when, where, and under what context the content appears on the site.

SFCC Slot System ​

SFCC uses a slot-based content system where:

  • Slots are predefined placeholders on pages (e.g., home-main-m)
  • Slot Configurations assign content to slots with scheduling and context
  • Campaigns group slot configurations with a shared time window
