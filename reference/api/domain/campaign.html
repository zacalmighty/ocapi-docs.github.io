Campaign Domain Entity ​

Campaign Domain Entity

The Campaign is the top-level domain object that represents a time-bound promotional campaign in SFCC. Campaigns control when content becomes visible on the website by activating slot configurations during a specific time window.

Domain Concepts ​

  • Campaign: A time-boxed container that activates slots between start and end dates
  • Slot Configuration: Links a content asset to a page slot with scheduling
  • Content Asset: The actual HTML content displayed in the slot

Lifecycle ​

  1. Excel wireframe is parsed into
  2. RefreshDTO is compiled into a Campaign with nested SlotConfigurations
  3. Campaign is serialized to OCAPI payload for SFCC sync

Represents an SFCC campaign with time-bound slots and linked content assets.

A Campaign is the primary domain entity that coordinates when content appears on the website. It contains slot configurations that link content assets to page slots during the campaign's active window.

Group: domain

Returns all unique content assets from this campaign.

Traverses all slot configurations and collects their linked assets, deduplicating by asset ID.

fromOcapiPayload(payload, payload.campaign, payload.assets, payload.slotConfigurations, payload.slotBindings) ​

Creates a Campaign instance from an OCAPI payload structure.

OCAPI payloads have a specific format with separate arrays for campaigns, assets, slot configurations, and slot bindings. This method reconstructs the Campaign domain object from that flattened structure.

Example ​

javascript
// Create a campaign for a morning refresh
const campaign = new Campaign({
  campaign_id: "loft-2026-01-26-r1",
  name: "New Arrivals Launch",
  description: "Homepage refresh for New Arrivals collection",
  start_date: "2026-01-26T00:00:00.000Z",
  end_date: "2026-01-26T15:00:00.000Z",
  enabled: true,
  slots: [
    {
      slot_id: "home-main-m",
      context: "global",
      assets: [{ id: "loft-2026-01-26-r1-homepage", name: "Homepage Content" }]
    }
  ]
});

// Reconstruct campaign from OCAPI payload (loaded via BrandContext.fileStore)
const payload = brand.fileStore.loadJsonFromPath("ocapi-payload.json");
const campaign = Campaign.fromOcapiPayload(payload);
console.log(campaign.getAssetIds()); // ["loft-2026-01-26-r1-homepage", ...]

const assets = campaign.getAllAssets();
console.log(`Campaign has ${assets.length} unique assets`);
assets.forEach(asset => console.log(`  - ${asset.id}`));

const assetIds = campaign.getAssetIds();
// ["loft-2026-01-26-r1-homepage", "loft-2026-01-26-r1-pph", ...]

const json = campaign.toJSON();
// Save via BrandContext.fileStore (domain doesn't do I/O directly)

// Get payload for OCAPI campaign creation
const ocapiPayload = campaign.toOCAPI();
// { campaign_id: "...", description: "...", enabled: true, ... }

// Load via BrandContext.fileStore, then hydrate
const data = brand.fileStore.loadJsonFromPath("campaign.json");
const campaign = Campaign.fromJSON(data);

// Load from ocapi-payload.json (generated by GenerateDevFiles)
const payload = require("./dev-env/loft/refreshes/2026-01-26/r1/ocapi-payload.json");
const campaign = Campaign.fromOcapiPayload(payload);
