Commands
⬇️

Pull

Sync with the team and fetch the latest campaign data from Smartsheet or Excel—one command.

⚙️

Build

Generate HTML from templates with guards that prevent overwriting work that’s already built or synced.

🚀

Push

Data quality checks first, then sync to SFCC staging. No surprises.

✅

Done

Generate the changeout email and commit. Your partner sees it on their next pull.

Quick Start ​

bash
npm install
make setup        # Configure your brand
make pull         # Sync + fetch data + see the dashboard
1
2
3

Three commands to get going: set your brand and data source, then pull to fetch the latest data and pick the date you’re working on. No config editing required.

Your Daily Loop ​

bash
make pull              # Start here — sync + fetch + pick your date
make status            # Pick refresh (sets active) + run action
make select            # Or switch date directly (sticky selection)
make build             # Generate HTML for that date
make push              # Validate + sync to SFCC staging
make done              # Changeout email
make commit            # Save for the team
