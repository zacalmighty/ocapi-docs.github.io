Commands

Pull

Git sync + fetch campaign data from Smartsheet or Excel in one command.

⚙️

Build

Generate HTML from Handlebars templates with safe guards against overwrites.

🚀

Push

Validate data quality, then sync to SFCC via OCAPI.

✅

Done

Generate changeout email and commit your work for the team.

Quick Start ​

bash
npm install
make setup        # Configure your brand
make pull         # Git sync + fetch data + see the dashboard
1
2
3

One command to start your day — pulls the latest from Git, fetches fresh data, shows everything that needs work.

Day-to-Day ​

bash
make pull              # Start here — sync + fetch + dashboard
make select            # Pick your working date (sticky)
make build             # Generate HTML for the selected date
make push              # Validate + sync to SFCC staging
make done              # Generate changeout email
make commit            # Save your work to Git
