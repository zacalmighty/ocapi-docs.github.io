Quick Start ​

bash
npm install
make setup        # Configure your brand
make pull         # Sync + fetch data + see the dashboard
1
2
3

Three commands to get going: set your brand and data source, then pull to fetch the latest data and pick the date you’re working on. No config editing required.

Your Daily Loop ​

bash
make pull              # Fetch latest data + auto-build new dates
make preview           # Build if stale + compose previews + file browser
make push              # Sync to SFCC + email + replicate steps
make commit            # Save for the team
make status            # Dashboard — switch dates, pick actions
