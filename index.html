Quick Start ​

bash
npm install
make setup        # Configure your brand
make status       # Open status hub (main entrypoint)
1
2
3

Three commands to get going: install, configure brand/source once, then enter the status hub. Use make pull from there whenever you need fresh source data.

Your Daily Loop ​

bash
make pull              # Fetch latest data + auto-build new dates
make status            # Dashboard — switch dates, pick actions
make refresh           # Build selected refresh (or use status action)
make push              # Sync to SFCC staging
make reports OP=report DATE=YYYY-MM-DD   # Zone/IPID detail
1

StepCommandWhat it does
1make pullFetch latest data and auto-build missing refreshes
2make statusPick refresh and run actions (build/push/upload/delete/detail)
3make pushData quality check + staging sync
4make reports OP=report DATE=...Per-refresh zone/IPID visibility for audit/handoff
