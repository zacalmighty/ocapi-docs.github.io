Glossary ​

Definitions of key terms used throughout the SFCC Campaign Automation documentation.

Code reference (source of truth): Actions — src/utils/helpers/action.js, src/config/app.config.js. Asset types and zones — src/config/asset.config.js, src/config/slots/*. Refresh ID rules — src/infrastructure/parsing/ExcelParser.js. Output paths — Output Paths, src/infrastructure/filesystem/pathBuilder.js.

A ​

Action ​

An instruction indicating how to process a zone. See Action Types. Source: src/utils/helpers/action.js, src/config/app.config.js (ACTION_TYPES).

ActionMeaning
LAUNCHCreate new content, new asset ID
UPDATEModify existing content, same ID
REMOVEDelete content from SFCC
NO_CHANGEKeep existing content, no processing

Asset ​

See Content Asset.

Asset ID ​

Unique identifier for a content asset in SFCC. See Asset ID Rules.

Single-zone: {brand}-{date}-{refreshId}-{assetType} — e.g., loft-2026-02-03-r1-pph

Multi-zone: {brand}-{date}-{refreshId}-{assetType}-{zone} — e.g., loft-2026-02-03-r1-homepage-hp-hero

Asset Registry ​

JSON file tracking current asset IDs for each zone. Enables NO_CHANGE action and asset reuse. See Asset Registry.

Asset Type ​

Category of promotional content (PPH, POPUP, HOMEPAGE, etc.). Source: src/config/asset.config.js, src/config/slots/*. See Slots & Asset Types.

B ​

Brand ​

A distinct e-commerce property. Currently: loft (LOFT) and ann (Ann Taylor).

BrandContext ​

Dependency injection container providing access to all services for a specific brand. The composition root of the application.

Build Guard ​

Safety check that prevents make build from overwriting already-built or already-synced dates. Reads sync-config.json and ocapi-payload.json to determine state. Bypassed by make build FORCE=1 (--force). See build.

Business Manager ​

Salesforce Commerce Cloud's administrative interface for managing content, products, and site configuration.

C ​

Campaign ​

Time-bound promotional entity in SFCC that coordinates when content appears on the website. Contains slot configurations and dates.

Campaign ID ​

Unique identifier for a campaign. Format: {brand}-{date}-{refreshId}.

Example: loft-2026-02-03-r1

CLI ​

Command Line Interface. The primary way to interact with the automation tool. See CLI Reference.

CompileRefresh ​

Use case that transforms Refresh DTOs into Campaign domain models.

Composition ​

The process of combining multiple zone templates into a single preview file.

Content Asset ​

A self-contained HTML fragment stored in SFCC's Content Library. Content assets are the atomic units of promotional content that fill slots on web pages. They contain HTML markup and inline CSS but cannot include <html>, <head>, or <body> tags. See Slots, Assets, Zones.

Content Library ​

SFCC's storage for content assets. Identified by SFCC_LIBRARY_ID.

Context ​

Scope of a slot configuration: global (site-wide) or category (category-specific).

D ​

Data Quality Gate ​

Automatic validation step in make push that checks for missing copy, duplicate IPIDs, unknown asset types, and other data issues before syncing to SFCC. Errors block the push; warnings prompt for confirmation. See push.

Date State ​

The lifecycle state of a refresh as shown in the make status dashboard. The full set of states is LIVE, SYNCED, UPDATED, READY, BUILD, and NEW. See Status States for definitions and next steps. Email is auto-generated by make push; make email can regenerate it standalone. See Command Reference.

Dev CLI ​

The set of commands intended for the web developer: registry, upload, test, check, clean, docs, log, test-brands. Run make dev to see the full list. See Command Reference.

Developer Mode ​

Asset type mode where HTML is provided directly (not rendered from templates). Used for complex layouts like Homepage.

Dry Run ​

Running a command without making actual changes. Use --dry-run flag.

Dev Files ​

The generated output files for a refresh: HTML templates, rendered previews, asset JSON files, and the OCAPI payload. Stored in dev-env/{brand}/refreshes/{date}/{refreshId}/.

DTO ​

Data Transfer Object — a plain object for passing data between application layers without business logic. The Refresh is a DTO that carries wireframe data from the parser to the compiler.

E ​

Excel Parser ​

Service that parses wireframe Excel files into Refresh DTOs. Supports multiple formats.

G ​

GenerateDevFiles ​

Use case that generates HTML/JSON assets and OCAPI payload from Campaign entities.

H ​

Handlebars ​

Template engine used for rendering HTML from templates. See Template Authoring.

Force Rebuild ​

Workflow for regenerating HTML after template changes or fixes. Use make build FORCE=1 to bypass the build guard and regenerate all assets, then make push FORCE=1 to re-sync. See best practices.

L ​

LAUNCH ​

Action indicating new content creation. Generates new asset ID and registers in registry.

N ​

NO_CHANGE ​

Action indicating content is unchanged from the previous refresh. Reuses the existing asset ID from the registry without regenerating HTML or syncing to SFCC. This is the most common action in wireframes. See Action Types.

O ​

OCAPI ​

Open Commerce API — Salesforce Commerce Cloud's REST API for managing content, campaigns, and slots programmatically. See OCAPI Readiness.

OCAPI Payload ​

JSON file (ocapi-payload.json) containing the complete campaign data formatted for SFCC API submission: campaign metadata, content assets (with HTML body), slot configurations, and slot bindings.

P ​

POD ​

Production instance in SFCC. Content is replicated from staging to PODs.

Preview ​

Composed view of multi-zone assets for visual verification before sync.

Producer CLI ​

The producer make targets: pull, build, preview, push, replicate, email, commit, status; plus setup, health. Force-rebuild after template edits: make build FORCE=1. Note: make push auto-generates the email. See Command Reference.

Pull ​

make pull — the daily starting command. Combines git sync, data fetch, status dashboard, and date selection into one step. See pull.

R ​

Refresh ​

A data transfer object (DTO) containing wireframe data for a specific date. Holds all asset types, zones, and items parsed from the Excel/Smartsheet source. The input to the generation process. See Refresh & Campaign.

Refresh Bundle ​

A conceptual collection of all refreshes for a single date (r1, r2, r3, etc.). Each refresh is stored in its own directory under dev-env/{brand}/refreshes/{date}/{refreshId}/; there is no single refresh-bundle.json file.

Refresh ID ​

Ordinal identifier for multiple refreshes on the same date: r1, r2, r3, etc. Assigned by start time order. Source: src/infrastructure/parsing/ExcelParser.js (_assignRefreshIds).

Registry ​

See Asset Registry.

Replication ​

Process of copying content from staging to production PODs. Currently requires manual trigger in Business Manager.

REMOVE ​

Action indicating content should be deleted from SFCC and unregistered.

S ​

SFCC ​

Salesforce Commerce Cloud. The e-commerce platform this tool integrates with.

Site ID ​

SFCC identifier for the website. Set via SFCC_SITE_ID environment variable.

SKIP ​

Deprecated. Use NO_CHANGE instead. If "SKIP" appears in a wireframe, the system logs an unknown-action warning and treats it as NO_CHANGE.

Slot ​

A designated area on an SFCC page where content can be displayed. Slots are filled by slot configurations.

SlotConfiguration ​

Domain entity linking a ContentAsset to a specific slot within a Campaign. Defines when, where, and what content appears.

Slot ID ​

Unique identifier for a slot in SFCC. Examples: global-promotion-banner, hp-top-banner.

Smartsheet ​

Cloud-based spreadsheet application used as a wireframe data source.

Status States ​

States shown in the make status dashboard. At most one refresh is LIVE (the one on the homepage right now). Source: status state labels in src/cli/prompts/ (datePicker stateLabel / stateIcon); sync state from sync-config.json.

StateConditionNext Step
LIVESynced and on site now: folder date is today, or current time is inside the refresh's start–end window (folder = nominal start; end shows span). Only one row is LIVE.make commit
SYNCEDSynced but not currently live (outside window and/or date not today)make replicate when ready
UPDATEDPreviously synced but source data changed since last sync (needs rebuild)make build then make push
READYocapi-payload.json exists, not yet pushedmake push
BUILDrefresh.json exists but no payloadmake build
NEWData fetched, not yet built (same as BUILD)make build

See status for details.

Staging ​

SFCC environment for testing content before production. Content syncs here first.

Sticky Selection (active refresh) ​

The currently selected refresh (date/r#), stored in dev-env/{brand}/.current-date (gitignored). Set by make status or make pull. Automatically used by make build, make push, make email, etc. so producers don't need to type DATE= on every command. See status.

Sync ​

Process of pushing campaign data to SFCC via OCAPI. Now accessed via make push, which adds automatic data quality validation. See push.

T ​

Template ​

Handlebars file used to generate HTML content. Located in templates/ directory.

Template Mode ​

Asset type mode where HTML is rendered from Handlebars templates using zone data.

U ​

UPDATE ​

Action indicating modification to existing content. Reuses existing asset ID from registry.

Upload ​

Process of pushing only content assets (not campaign/slots) to SFCC. See CLI: upload.

Use Case ​

Application layer class that orchestrates domain operations. Examples: GenerateDevFiles, SyncToSfcc, ParseExcel.

V ​

Validation ​

Process of checking templates and refresh data for SFCC compatibility. Runs automatically as part of make push. See Validation Rules.

VitePress ​

Static site generator used for this documentation.

W ​

Wireframe ​

Excel or Smartsheet document containing campaign content data — the source input for the automation. Wireframes specify what promotional content goes live on which dates, including copy, links, actions (LAUNCH/UPDATE/REMOVE), and zone assignments. Also referred to as "the Excel file" or "the spreadsheet."

Z ​

Zone ​

A specific content area within an asset type. Multi-zone asset types (like Homepage) have many zones. See Slots, Assets, Zones.

Zone Key ​

Identifier for a zone within an asset type. Examples: HP_TOP_BANNER, HP_HERO, MAIN.
