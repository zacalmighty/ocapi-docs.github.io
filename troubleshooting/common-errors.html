Common Errors ​

Reference for common error messages and how to resolve them.

Build Guard Messages ​

"Already synced" (build guard) ​

Message:

⚠  2026-02-10 was already synced on 2026-02-09T16:45:00Z
   Use: make select  to pick another date
   Use: make build FORCE=1  to force rebuild (rare)
1
2
3

Cause: Another producer (or you) already pushed this date to SFCC. The build guard prevents accidental overwrites.

Solution:

  • Normal: Run make select to pick a different date
  • Re-push needed: Run make build FORCE=1 to force rebuild, then make push FORCE=1

"Already synced" (push guard) ​

Message:

  • SFCC already has this date; no changes to sync for 2026-02-10/r1.
1

Cause: This refresh was already synced to SFCC. Push exits without calling OCAPI so you don’t re-run sync unnecessarily; the intended next steps are make replicate, make done, and make commit. When re-pushing with FORCE=1, only changed items are synced; if nothing changed, the same message is shown and slot binding is skipped.

What to do: Run make replicate, then make done, then make commit. Use make push FORCE=1 only when you need to re-push (e.g. after a hotfix).

Solution:

  • Normal: Run make replicate, then make done, then make commit
  • Re-push needed (e.g. after hotfix): Run make push FORCE=1 (or make push --force via CLI)

"Already built" ​

Message:

ℹ  This date is already built.
   Use: make build  (then save a template/config to rebuild) or make build FORCE=1
   Use: make push    to sync to SFCC
1
2
3

Cause: The HTML and OCAPI payload already exist for this date. No need to regenerate.

Solution:

  • Ready to deploy: Run make push
  • Need to rebuild: Run make build (then save a template or config file to rebuild) or make build FORCE=1

"Data quality check failed" ​

Message:

❌ Data quality check failed:
   • 3 items missing copy (LAUNCH)
   • 1 missing destination ID (HOMEPAGE)
1
2
3

Cause: The wireframe data has issues that would cause problems on the live site.

Solution:

  1. Fix the data in the Excel/Smartsheet source
  2. Re-fetch with make pull
  3. Rebuild with make build
  4. Push again with make push

"This date hasn't been synced yet" ​

Message:

⚠  This date hasn't been synced yet.
   Run: make push
1
2

Cause: Running make done before make push.

Solution: Run make push first, then make done.

CLI Errors ​

"No refresh found" ​

Error:

❌ No refresh found. Run 'make pull' first.
1

Cause: No refresh.json exists for the specified date or brand.

Solution:

bash
# Fetch wireframe data first
make pull

# Then build
make build
1
2
3
4
5

"Config not found" ​

Error:

❌ Configuration not found. Run 'make setup' to create.
1

Cause: Missing dev-env/.ocapi-config.json.

Solution:

bash
make setup
1

"No date selected" ​

Error:

❌ No date selected. Run 'make select' or pass DATE=
1

Cause: No sticky date set and no DATE= provided.

Solution:

bash
make select            # Interactive picker
make select DATE=2026-02-03  # Direct set
1
2

"Invalid brand" ​

Error:

❌ Invalid brand: 'xyz'. Valid brands: loft, ann
1

Cause: Unrecognized brand key.

Solution: Use loft or ann:

bash
make switch TO=loft
1

"Date is required" ​

Error:

❌ Usage: make delete DATE=2026-01-26
1

Cause: Command requires --date flag.

Solution:

bash
make delete DATE=2026-02-03
1

OCAPI Errors ​

"OCAPI not enabled" ​

Error:

❌ OCAPI is not enabled. Run 'make setup' to enable.
1

Cause: OCAPI toggle is off in configuration.

Solution:

bash
make setup     # Enable OCAPI in the wizard
make health    # Verify connection
1
2

"Missing environment variables" ​

Error:

❌ Missing required OCAPI environment variables:
   - SFCC_CLIENT_SECRET
1
2

Cause: Required environment variable not set.

Solution:

  1. Create/edit .env file:
bash
SFCC_CLIENT_SECRET=your-secret-here
1
  1. Verify:
bash
make health
1

"401 Unauthorized" ​

Error:

❌ OCAPI Error: 401 Unauthorized
   Endpoint: /campaigns/loft-2026-02-03-r1
1
2

Cause: Invalid or expired OAuth credentials.

Solution:

  1. Check credentials in .env:
bash
SFCC_CLIENT_ID=correct-id
SFCC_CLIENT_SECRET=correct-secret
1
2
  1. Verify with health check:
bash
make health
1
  1. If credentials recently rotated, update .env.

"404 Not Found" ​

Error:

❌ OCAPI Error: 404 Not Found
   Asset: loft-2026-02-03-r1-homepage-hp_top_banner
1
2

Cause: Trying to UPDATE an asset that doesn't exist in SFCC.

Solution:

  • Change action to LAUNCH in wireframe, or
  • Sync the asset first with LAUNCH action

"429 Rate Limited" ​

Error:

⚠️ Rate limited. Retrying in 5s...
1

Cause: Too many API requests.

Solution: Wait and retry (automatic). If persistent:

  • Reduce concurrent operations
  • Wait longer between batches

"Connection timeout" ​

Error:

❌ OCAPI Error: ETIMEDOUT
   Could not reach SFCC API
1
2

Cause: Network issue or VPN not connected.

Solution:

  1. Check VPN connection
  2. Verify SFCC_BASE_URL is correct
  3. Test network: curl $SFCC_BASE_URL

Validation Errors ​

"Forbidden tag" ​

Error:

✖ hp_top_banner.html:1 — Forbidden tag: <!DOCTYPE html>
1

Cause: Template contains HTML tags that SFCC doesn't allow in content assets.

Solution: Remove forbidden tags from template:

  • <!DOCTYPE html>
  • <html>, </html>
  • <head>, </head>
  • <body>, </body>
  • <meta>
  • <title>

Templates should contain only fragment HTML.

"Unclosed block" ​

Error:

✖ template.html:25 — Unclosed block: {​{#each items}}
1

Cause: Handlebars block not properly closed.

Solution: Add closing tag:

handlebars
{​{#each items}}
  <div>{​{this.name}}</div>
{​{/each}}  <!-- Add this -->
1
2
3

"Unknown helper" ​

Error:

✖ template.html:10 — Unknown helper: 'customHelper'
1

Cause: Using a Handlebars helper that isn't registered.

Solution:

  1. Check for typo in helper name
  2. Use built-in helpers (see Template Authoring)
  3. Or register custom helper in rendering/engine.js

Parser Errors ​

"Cannot parse sheet" ​

Error:

❌ Cannot parse sheet 'Q1'. Unrecognized format.
1

Cause: Excel sheet doesn't match expected format.

Solution:

  1. Specify format explicitly:
bash
node src/cli/index.js excel loft --mode=converted
1
  1. Check sheet structure matches expected format (see Wireframe Format)

"Missing required column" ​

Error:

❌ Missing required column: 'Action'
1

Cause: Expected column not found in Excel.

Solution: Verify Excel has required columns:

  • Zone/Slot identifier
  • Action (LAUNCH, UPDATE, etc.)
  • Date (or date header)

"Invalid date format" ​

Error:

❌ Invalid date: 'Feb 3, 2026'. Expected YYYY-MM-DD.
1

Cause: Date not in ISO format.

Solution: Use YYYY-MM-DD format in wireframe:

  • ✅ 2026-02-03
  • ❌ Feb 3, 2026
  • ❌ 02/03/2026

1

Cause: File system permissions issue.

Solution:

bash
# Fix permissions
chmod -R 755 dev-env/

# Or check if file is locked by another process
lsof +D dev-env/
1

4

"Directory not found" ​

Error:

❌ ENOENT: no such file or directory, 'dev-env/xyz/refreshes'
1

Cause: Brand directory doesn't exist.

Solution:

bash
mkdir -p dev-env/loft/refreshes
1

Getting Help ​

If you encounter an error not listed here:

  1. Check the error message for hints
  2. Run with debug mode: DEBUG=1 make build
  3. Run make status to see the current state
  4. Run make health to check SFCC connectivity
  5. Search existing documentation
  6. Contact the development team
