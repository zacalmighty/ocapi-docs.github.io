Frequently Asked Questions ​

General ​

What does this tool do? ​

Transforms Smartsheet wireframes into production-ready SFCC content:

  • Fetches data from Smartsheet
  • Generates HTML from templates
  • Syncs to SFCC via OCAPI
  • Manages asset versions

How much time does it save? ​

Typical refresh: 2-4 hours → 15 minutes (85% reduction)

Workflow ​

What's the difference between pull and build? ​

CommandWhat It DoesInputOutput
make pullGit sync + fetch data + dashboardSmartsheet/Excelrefresh.json
make buildGenerate HTML + OCAPI payloadrefresh.jsonHTML + JSON + ocapi-payload.json

pull gets the data and shows you what's available; build processes a specific date.

Why did make build skip my date? ​

Build guards prevent accidental overwrites:

  • "Already synced" — someone already pushed this date to SFCC. Use make edit to force rebuild, or make select for a different date.
  • "Already built" — HTML and payload already exist. Use make push to sync, or make edit to rebuild after template changes.

Can I process multiple dates at once? ​

Producers work one date at a time via make select + make build. This is by design — build guards prevent accidental overwrites across dates. Developers can use make demo to build multiple dates at once.

How do I preview changes before syncing? ​

bash
make preview
1

Uses your selected date. Shows preview links in the output.

What if I need to edit content after generating? ​

Edit files in dev-env/{brand}/refreshes/{date}/r#/:

  • HTML: preview/templates/{assetType}/*.html
  • JSON: assets/*.json

Then rebuild:

bash
make edit
1

Uses your sticky date. No need for DATE=.

Will my custom HTML get overwritten? ​

No. Assets in DEVELOPER mode preserve custom HTML across fetches. Only TEMPLATE mode assets regenerate.

See Asset Modes.

What if another producer already built my date? ​

The build guard will tell you. Run make pull to get their latest work, then make status to see the full board. Pick a different date with make select.

See Multi-Producer Guide.

See Environment Setup.

Can I sync to production directly? ​

No. The workflow is:

  1. make push → Validates data quality + syncs to staging
  2. make replicate → Opens manual replication checklist for production

This prevents accidental production pushes.

How do I delete content from SFCC? ​

bash
make delete DATE=2026-02-03
1

Or manually in Business Manager.

Troubleshooting ​

"Asset not found" error ​

The asset doesn't exist in SFCC yet. Check:

  1. Was the action set to LAUNCH?
  2. Did the initial sync succeed?

"Campaign already exists" error ​

A campaign with the same ID already exists. Either:

  1. Use UPDATE action instead of LAUNCH
  2. Delete the existing campaign first

"Authentication failed" error ​

bash
make health
1

Check your .env credentials.

"Rate limited" error ​

The API is throttling requests. The client retries automatically, but if it persists:

  1. Wait a few minutes
  2. Reduce batch size
  3. Check for other processes hitting the API

Template not found ​

bash
make check
1

Ensure the template file exists in templates/{assetType}/template.html.

Empty preview ​

Check if:

  1. refresh.json has content
  2. Template exists for the asset type
  3. No validation errors
bash
make check
1

Sync1-2 minutes (depends on asset count)

Can I speed up syncing? ​

The API client uses batch operations and rate limiting. Speed is mostly limited by SFCC API response times.
