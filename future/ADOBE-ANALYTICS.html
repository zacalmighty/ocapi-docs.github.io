Adobe Analytics Integration Guide ​

Status: Future Enhancement
Priority: Phase 2
Dependencies: Adobe I/O Console access, Adobe Analytics admin access

Overview ​

This document outlines how to integrate Adobe Analytics with the SFCC Campaign Automation system to track asset performance and provide insights on CTR, revenue, and conversion.

Prerequisites ​

1. Adobe I/O Console Setup ​

  1. Go to Adobe I/O Console
  2. Create a new project
  3. Add the "Adobe Analytics" API
  4. Create a Service Account (JWT) credential
  5. Download the private key file
  6. Note your:
    • Client ID
    • Client Secret
    • Technical Account ID
    • Organization ID

2. Adobe Analytics Configuration ​

  1. Create/designate an eVar for IPID tracking

    • Recommended: eVar15 (or any available)
    • Name: "Campaign IPID"
    • Expiration: Hit
    • Allocation: Most Recent

  2. Configure Adobe Launch

    • Create a rule: "Track IPID Clicks"
    • Condition: Click on elements with [data-ipid]
    • Action: Set eVar15 = %this.dataset.ipid%
    • Action: Send beacon (event1 = click)

  3. Get Report Suite IDs

    • LOFT production: loftprod (example)
    • Ann Taylor production: annprod (example)

Environment Variables ​

Add to .env:

bash
# Adobe Analytics API (from Adobe I/O Console)
ADOBE_CLIENT_ID=your_client_id_here
ADOBE_CLIENT_SECRET=your_client_secret_here
ADOBE_ORG_ID=your_org_id@AdobeOrg
ADOBE_TECH_ACCOUNT_ID=your_tech_account@techacct.adobe.com
ADOBE_PRIVATE_KEY_PATH=./certs/adobe-private.key

# Company ID (from Adobe Analytics admin)
ADOBE_COMPANY_ID=your_company_id

# Report Suite IDs (one per brand)
ADOBE_RSID_LOFT=loftprod
ADOBE_RSID_ANN=annprod

# Which eVar holds the IPID
ADOBE_IPID_DIMENSION=variables/evar15

# Optional: Cache TTL in seconds (default: 3600)
ADOBE_CACHE_TTL=3600

Service Implementations ​

AdobeAuthService ​

Handles JWT-based authentication with Adobe IMS:

javascript
class AdobeAuthService {
  constructor(config) {
    this.clientId = config.clientId;
    this.clientSecret = config.clientSecret;
    this.techAccountId = config.techAccountId;
    this.orgId = config.orgId;
    this.privateKey = fs.readFileSync(config.privateKeyPath);
    this._token = null;
    this._tokenExpiry = null;
  }

  async getToken() {
    // Return cached token if valid
    if (this._token && Date.now() < this._tokenExpiry) {
      return this._token;
    }

    // Create JWT and exchange for access token
    const jwt = this._createJwt();
    const response = await fetch("https://ims-na1.adobelogin.com/ims/exchange/jwt", {
      method: "POST",
      headers: { "Content-Type": "application/x-www-form-urlencoded" },
      body: new URLSearchParams({
        client_id: this.clientId,
        client_secret: this.clientSecret,
        jwt_token: jwt,
      }),
    });

    const data = await response.json();
    this._token = data.access_token;
    this._tokenExpiry = Date.now() + data.expires_in * 1000 - 60000;
    return this._token;
  }

  _createJwt() {
    const payload = {
      exp: Math.floor(Date.now() / 1000) + 300,
      iss: this.orgId,
      sub: this.techAccountId,
      aud: `https://ims-na1.adobelogin.com/c/${this.clientId}`,
      "https://ims-na1.adobelogin.com/s/ent_analytics_bulk_ingest_sdk": true,
    };
    return jwt.sign(payload, this.privateKey, { algorithm: "RS256" });
  }
}

AdobeAnalyticsService ​

Fetches reports from Adobe Analytics API 2.0:

javascript
class AdobeAnalyticsService {
  constructor({ brand, authService, config }) {
    this.brand = brand;
    this.auth = authService;
    this.config = config;
    this.baseUrl = "https://analytics.adobe.io/api";
  }

  /**
   * Get performance data for a date range.
   * @param {string} startDate - YYYY-MM-DD
   * @param {string} endDate - YYYY-MM-DD
   * @returns {Promise<Object[]>} Performance data by IPID
   */
  async getPerformance(startDate, endDate) {
    const token = await this.auth.getToken();
    const rsid = this.config.reportSuites[this.brand.id];

    const response = await fetch(`${this.baseUrl}/${this.config.companyId}/reports`, {
      method: "POST",
      headers: {
        Authorization: `Bearer ${token}`,
        "x-api-key": this.config.clientId,
        "x-proxy-global-company-id": this.config.companyId,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        rsid,
        globalFilters: [
          {
            type: "dateRange",
            dateRange: `${startDate}T00:00:00/${endDate}T23:59:59`,
          },
        ],
        metricContainer: {
          metrics: [
            { id: "metrics/occurrences", columnId: "impressions" },
            { id: "metrics/event1", columnId: "clicks" },
            { id: "metrics/revenue", columnId: "revenue" },
            { id: "metrics/orders", columnId: "orders" },
          ],
        },
        dimension: this.config.ipidDimension,
        settings: { limit: 100, page: 0 },
      }),
    });

    return this._processResponse(await response.json());
  }

  /**
   * Get top performers by metric.
   * @param {string} metric - clicks, revenue, orders
   * @param {number} limit - Number of results
   */
  async getTopPerformers(metric = "clicks", limit = 10) {
    // Similar to getPerformance but sorted by metric
  }

  /**
   * Compare two IPIDs.
   * @param {string} ipidA - First IPID
   * @param {string} ipidB - Second IPID
   * @param {string} startDate - Start date
   * @param {string} endDate - End date
   */
  async compare(ipidA, ipidB, startDate, endDate) {
    // Fetch data for both IPIDs and calculate differences
  }

  _processResponse(data) {
    return (data.rows || []).map((row) => ({
      ipid: row.value,
      impressions: row.data[0] || 0,
      clicks: row.data[1] || 0,
      revenue: row.data[2] || 0,
      orders: row.data[3] || 0,
      ctr: row.data[0] > 0 ? ((row.data[1] / row.data[0]) * 100).toFixed(2) : 0,
    }));
  }
}

Technical Notes ​

Rate Limits ​

  • Adobe API has rate limits (~10 requests/second)
  • Implement exponential backoff for retries
  • Cache responses locally to minimize API calls

Caching Strategy ​

  • Cache performance data for 1 hour (configurable)
  • Store in dev-env/{brand}/performance-cache.json
  • Invalidate cache on demand with make performance --no-cache

IPID Matching ​

  • IPID format in templates: data-ipid=""
  • Must match exactly what's sent to Adobe Analytics
  • Format: {brand}-{yearWeek}-{zone}-{sequence}

Error Handling ​

  • Handle expired tokens gracefully (auto-refresh)
  • Fallback to cached data if API unavailable
  • Log API errors for debugging
