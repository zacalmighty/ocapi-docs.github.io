Content Model ​

How promotional content maps from wireframe concepts to SFCC structures, and how to add new asset types.

The Hierarchy ​

Content Assets ​

A ContentAsset is an HTML fragment stored in SFCC's content library — the atomic unit of promotional content.

PropertyDescription
idUnique asset identifier
nameDisplay name in Business Manager
c_bodyOCAPI-formatted body (escaped HTML)
contentSanitized HTML content

Slot Configurations ​

A SlotConfiguration binds a ContentAsset to a specific page slot within a Campaign.

PropertyDescription
slot_idSFCC slot ID (e.g., "global-promotion-banner")
configuration_idUnique config ID for OCAPI
context"global" or "category"
context_idCategory ID (for category-scoped slots)
start_date / end_dateActivation schedule
syncStrategyHow this slot syncs: content-slot, plp-callout, etc.

Context Types ​

ContextDescriptionExample
globalSame content site-wideHomepage banner, PPH
categoryContent scoped to a categoryPLP header, Coupons

Category Slot Fanout ​

For category-scoped slots, siteLocation may contain multiple category IDs. The system fans out a single asset into one slot binding per category.

Zones ​

A Zone is a wireframe concept representing a specific content area within an asset type. Zones are stored as ordered arrays preserving the original sequence from the Excel source.

Normalization

All actions, devices, and site locations are normalized at parse time. For example, NO CHANGE/LINK SAME becomes NO_CHANGE, RESPONSIVE D & M becomes BOTH, and POP UP becomes POPUP.

Adding a New Asset Type ​

Step 1: Add to asset.config.js ASSET_TYPES ​

javascript
MY_NEW_ASSET: {
  active: true,                       // Set false to "hold" until ready
  mode: "TEMPLATE",                   // TEMPLATE | DEVELOPER | DATA
  syncStrategy: "content-slot",       // content-slot | plp-callout | data
  slot: { id: "my-slot-id", context: "global" },
  template: "my-asset/template",
  // Optional:
  zones: ["ZONE_A", "ZONE_B"],        // Multi-zone
  categoryMapping: { ... },           // For category-scoped
  externalResources: { stylesheets: [...], scripts: [...] },
},

Active vs Inactive ​

| active: true | Processed by build/preview/sync | | active: false | Parsed but skipped; no HTML, no OCAPI |

Use active: false when the slot doesn't exist on SFCC yet, the template isn't ready, or the type is for a future phase.
