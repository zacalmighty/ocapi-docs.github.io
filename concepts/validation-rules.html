Validation Rules ​

The system validates data at multiple stages to catch errors early. This page documents what's validated, when, and what happens on failure.

Validation Pipeline ​

Stage 1: Parsing Validation ​

Validates raw Excel data during parsing.

Header Detection ​

CheckFails WhenError
Required headers presentASSET_TYPE or ACTION column missing"Cannot detect sheet format"
Header row foundNo matching headers in first 10 rows"No header row detected"

Row Validation ​

CheckFails WhenError
Date parseableREFRESH_DATE is not a valid dateRow skipped with warning
Action recognizedACTION not in known listDefaults to NO_CHANGE
Asset type recognizedASSET_TYPE not in any alias mapLogged as unknown, included as-is

Stage 5: Template Validation ​

Forbidden HTML Tags ​

Templates must not contain full-page HTML structure tags. The system strips these if found:

Forbidden TagReason
<!DOCTYPE>SFCC wraps content in its own page
<html>Content is injected into existing page
<head>, <body>Only <div> and inline content allowed
<meta>, <title>Page metadata managed by SFCC
<script>Security — scripts go through SFCC resource pipeline
<style>Styles go through external CSS
<iframe>, <form>Security restrictions
