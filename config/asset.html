Asset Types Configuration ​

Where asset type definitions live and how they relate to slot resolution.

Two config files ​

FileRole
src/config/asset.config.jsSource of truth for asset types and patterns. Defines ASSET_TYPES, ZONE_TEMPLATE_VARIANTS, TEMPLATE_PATTERNS, ASSET_TYPE_PATTERNS, and HOMEPAGE_ZONE_PATTERNS.
src/config/slots.config.jsImports from asset.config.js and adds resolution helpers (e.g. resolveAssetType, getSyncStrategy, getHtmlSource). Used by the rest of the app for slot resolution and behavior.

When you add or change an asset type, you edit asset.config.js. The slots config re-exports and derives from it.

What lives in asset.config.js ​

  • ASSET_TYPES — Each key (PPH, POPUP, HOMEPAGE, PLP_HEADER, etc.) has: active, mode, syncStrategy, slot, template, optional zones, externalResources, categoryMapping, contextIdByBrand, etc.
  • ZONE_TEMPLATE_VARIANTS — Template variants per zone (e.g. HP_HERO variants).
  • TEMPLATE_PATTERNS — Regex patterns mapping wireframe/Excel names to template paths.
  • ASSET_TYPE_PATTERNS — Regex patterns mapping Excel asset type strings to canonical keys (e.g. DISCLAIMER → POPUP, FP → PLP_PROMO).
  • HOMEPAGE_ZONE_PATTERNS — Maps standalone Excel types (e.g. CAT A, SLOT 1) into HOMEPAGE zone keys so they merge into the homepage asset.

What lives in slots.config.js ​

  • Imports ASSET_TYPES, getAssetTypeConfig, isActive, and the pattern arrays from asset.config.js.
  • Defines resolution and helper functions used by ExcelParser, RenderingEngine, OcapiPayload, etc.: resolveAssetType, getSyncStrategy, resolveSlotConfig, getHomepageZoneKey, isMultiZone, and others.
  • Builds SLOT_REGISTRY and related structures for the runtime.

So: definitions in asset.config, resolution and API in slots.config.

Adding a new asset type ​

  1. Add the type in asset.config.js under ASSET_TYPES (active, mode, syncStrategy, slot, template, and any zones or categoryMapping).
  2. If Excel uses different names, add entries to ASSET_TYPE_PATTERNS in asset.config.js (order matters).
  3. If it merges into HOMEPAGE, add an entry to HOMEPAGE_ZONE_PATTERNS in asset.config.js.
  4. If mode is TEMPLATE, add a template under templates/{type}/template.html.
  5. Test: Run make excel (or point to your Excel) and make build for a date that includes the new type.

See Asset Types Guide for step-by-step and code snippets.
