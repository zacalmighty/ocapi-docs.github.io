Asset Registry ​

The Asset Registry tracks the current asset ID for each zone, enabling asset reuse and the NO_CHANGE action.

Purpose ​

The registry answers: "What content asset is currently live for this zone?"

This enables:

  • NO_CHANGE action: Reuse existing asset without reprocessing
  • UPDATE action: Modify existing asset (same ID)
  • Asset continuity: Track what's deployed across refreshes

File Location ​

dev-env/{brand}/asset-registry.json
1

Entry Properties ​

PropertyDescription
currentAssetIdThe active asset ID in SFCC
launchedAtDate when asset was first created (LAUNCH)
refreshIdRefresh ID that created this asset
lastUpdatedTimestamp of last modification
syncedAtTimestamp of last successful sync

How Actions Affect Registry ​

ActionRegistry Effect
LAUNCHCreates new entry with new asset ID
UPDATEUpdates lastUpdated, keeps same currentAssetId
REMOVEDeletes entry
NO_CHANGENo change (reads existing entry)

Registry Operations ​

View Registry ​

bash
make registry
1

Bootstrap Registry ​

Rebuild registry from existing refresh directories:

bash
make registry ARGS="--bootstrap"
1

Use when:

  • Registry was accidentally deleted
  • Starting fresh but files exist
  • Registry got out of sync

Clear Registry ​

Remove all entries:

bash
make registry ARGS="--clear"
1

WARNING

Clearing the registry means all zones become "unassigned". Next LAUNCH will create new asset IDs for everything.

API Usage ​

javascript
const { AssetRegistry } = require("./infrastructure/registry/AssetRegistry");

const registry = new AssetRegistry(brandKey);
await registry.load();

// Get current asset ID for a zone
const assetId = registry.getCurrentAssetId("HOMEPAGE", "HP_TOP_BANNER");

// Check if zone has entry
const hasEntry = registry.has("HOMEPAGE", "HP_TOP_BANNER");

// Register new asset (on LAUNCH)
registry.register({
  assetType: "HOMEPAGE",
  zoneKey: "HP_TOP_BANNER",
  assetId: "loft-2026-02-03-r1-homepage-hp_top_banner",
  launchedAt: "2026-02-03",
  refreshId: "r1",
});

// Mark as synced
registry.markSynced("HOMEPAGE", "HP_TOP_BANNER");

// Remove entry (on REMOVE)
registry.unregister("HOMEPAGE", "HP_TOP_BANNER");

// Save changes
await registry.save();

Sync Status ​

The registry tracks sync status via syncedAt:

StateMeaning
syncedAt presentAsset has been synced to SFCC
syncedAt missingAsset is local-only
syncedAt < lastUpdatedAsset modified since last sync

Troubleshooting ​

"Asset not found in registry" ​

The zone has no entry. Use LAUNCH action to create a new asset.

Registry out of sync ​

If registry doesn't match SFCC reality:

  1. Bootstrap from local files: make registry ARGS="--bootstrap"
  2. Or clear and start fresh: make registry ARGS="--clear"

Multiple refreshes for same date ​

Each refresh (r1, r2, etc.) can have different assets. The registry tracks the most recent LAUNCH for each zone.
