Asset Registry ​

The registry tracks the current asset ID for each zone, enabling asset reuse and the NO_CHANGE action. Registry data lives in each refresh manifest; the RefreshRegistryResolver merges per-refresh registry sections to provide a "current" view.

Purpose ​

The registry answers: "What content asset is currently live for this zone?"

This enables:

  • NO_CHANGE action: Reuse existing asset without reprocessing
  • UPDATE action: Modify existing asset (same ID)
  • Asset continuity: Track what's deployed across refreshes

Storage ​

Registry data is stored in each refresh.json manifest under a registry section:

dev-env/{brand}/refreshes/{date}/{refreshId}/refresh.json
1

Items (and IPIDs) remain in assets/*.json; the registry section holds only assetId, launchedAt, and refreshId per zone.

Entry Properties ​

PropertyDescription
assetIdThe active asset ID in SFCC
launchedAtDate when asset was first created (LAUNCH)
refreshIdRefresh ID that created this asset

How the Resolver Works ​

RefreshRegistryResolver scans refreshes by date descending, merges registry sections per zone (first-wins), and provides:

  • getCurrentAssetId(assetType, zoneKey) — current asset ID for a zone
  • getEntry(assetType, zoneKey) — full entry with optional items from asset files
  • getRegistryWithItems() — merged registry with items loaded from asset files
  • getLiveRefresh() — date and refreshId of most recent entry

Registry Visibility Operations ​

Use slim reports for registry-adjacent visibility:

bash
make reports OP=report DATE=YYYY-MM-DD
make reports OP=history ARGS="--zone=ZONE_KEY"
make reports OP=coverage

How Actions Affect Registry ​

ActionRegistry Effect
LAUNCHAdds entry with new asset ID to manifest
UPDATEKeeps same assetId (no change)
REMOVEAdds removed: true or removes entry
NO_CHANGENo change (reads from resolver)

API Usage ​

javascript
const { getRefreshRegistryResolver } = require("./infrastructure/registry");
const resolver = getRefreshRegistryResolver(brandId, fileStore);

// Get current asset ID for a zone
const assetId = resolver.getCurrentAssetId("HOMEPAGE", "HP_TOP_BANNER");

// Get entry with optional items
const entry = resolver.getEntry("HOMEPAGE", "HP_TOP_BANNER");

// Full merged registry with items
const withItems = resolver.getRegistryWithItems();

Troubleshooting ​

"Asset not found in registry" ​

The zone has no entry. Use LAUNCH action to create a new asset.

Registry out of sync ​

Run a fresh pull and refresh to rebuild local snapshots:

make pull && make refresh DATE=YYYY-MM-DD
