Brands Configuration ​

The system supports multiple brands with brand-specific configuration for environment URLs, default settings, and data sources.

Supported Brands ​

BrandKeyStatus
LOFTloftProduction ready
Ann TaylorannProduction ready

Brand Configuration ​

Defined in src/config/app.config.js:

javascript
const BRANDS_CONFIG = {
  loft: {
    name: 'LOFT',
    qa_link: 'https://qa.loft.com',
    stg_link: 'https://stg.loft.com',
    stg_test_link: 'https://stg-test.loft.com',
    prod_link: 'https://www.loft.com',
  },
  ann: {
    name: 'Ann Taylor',
    qa_link: 'https://qa.anntaylor.com',
    stg_link: 'https://stg.anntaylor.com',
    stg_test_link: 'https://stg-test.anntaylor.com',
    prod_link: 'https://www.anntaylor.com',
  },
};

SFCC Configuration per Brand ​

SFCC credentials are brand-agnostic in the .env file, but SFCC_SITE_ID and SFCC_LIBRARY_ID should match the target brand:

bash
# For LOFT
SFCC_SITE_ID=Loft
SFCC_LIBRARY_ID=Library - Loft

# For Ann Taylor
SFCC_SITE_ID=AnnTaylor
SFCC_LIBRARY_ID=Library - AnnTaylor

Makefile Brand Variables ​

The Makefile auto-detects the Excel file based on the BRAND variable:

VariablePurposeValue
BRANDActive brand (loft or ann)Read from config or env
BRAND_EXCELAuto-resolved Excel pathdocs/excel/LOFT (Converted).xlsx or docs/excel/Ann (Converted).xlsx
EXCEL_FILEOverride pathFrom config or fallback to BRAND_EXCEL

BRAND_EXCEL is computed in the Makefile as:

makefile
BRAND_EXCEL = $(shell node -e "console.log('$(BRAND)'==='ann'?'docs/excel/Ann (Converted).xlsx':'docs/excel/LOFT (Converted).xlsx')")
1

The ensure-config target automatically updates the config file when the BRAND changes, so switching brands always uses the correct Excel source.

API Functions ​

javascript
const { getBrandKeys, isValidBrand, getBrandDefaults } = require('./config/app.config');

// Get all brand keys
getBrandKeys(); // ['loft', 'ann']

// Validate brand
isValidBrand('loft'); // true
isValidBrand('invalid'); // false

// Get defaults
getBrandDefaults('loft'); // { name: 'LOFT', defaultExcel: '...' }
