Smartsheet Wireframe Guide ​

This guide is for the Ecomm team who manages campaign wireframes in Smartsheet.

Your Role ​

You own the wireframe. Producers pull your data, build it, preview it, then push to staging.

Action Values ​

Use these values in the Action column:

ActionWhen to UseResult
LAUNCHNew contentCreates new asset
UPDATEChange existingUpdates asset content
REMOVEDelete contentRemoves asset from SFCC
NO_CHANGEKeep as-isNo processing needed

Switching to Smartsheet ​

The web producer switches to Smartsheet via:

bash
make setup
1

They choose Smartsheet as the data source in the wizard. They need SMARTSHEET_API_KEY in .env and the sheet ID set via make setup (first time only). To switch back to local Excel, run make setup again and choose Local Excel file.

When Data Gets Pulled ​

The web producer runs:

bash
make pull         # Git sync + fetch wireframe data + auto-build + status dashboard
make refresh      # Build selected refresh when needed
make reports OP=report DATE=...   # View zone/IPID detail
1
2
3

make pull reads your Smartsheet (or Excel file), creates local JSON files, and auto-builds new dates. The producer then picks a date from the interactive status hub. When using Smartsheet, make pull CONVERT=1 fetches the latest sheet and converts it to Excel format.

What Happens Next ​

After you update the wireframe:

  1. Web producer runs make pull — fetches the latest data, auto-builds new dates, and sees the dashboard
  2. Producer runs make refresh and make reports OP=report DATE=... — rebuilds and reviews zone/IPID visibility
  3. Producer runs make push — validates data quality and syncs to SFCC staging (auto-generates email)
  4. After QA, replication to production is manual in Business Manager

Making Updates ​

Same-Day Updates ​

If you need to change content for today:

  1. Update the wireframe in Smartsheet
  2. Let the web producer know
  3. They re-fetch and re-sync

Future Updates ​

Plan ahead by adding rows for future dates. The tool only processes dates you specify.

Emergency Updates ​

For urgent changes, the web producer can directly edit the JSON files without waiting for a Smartsheet update.

Common Mistakes ​

MistakeProblemFix
Wrong actionLAUNCH creates duplicatesUse UPDATE for existing
Missing dateContent not foundEnsure date format is correct
Bad linksBroken on siteVerify URLs before adding
Empty fieldsTemplate errorsFill all required fields

Validation ​

The tool validates your data before syncing:

  • Required fields present
  • URLs are valid format
  • Dates are parseable
  • Actions are recognized

Errors appear in the terminal with specific row/field info.
