Campaign Lifecycle ​

End-to-end path from wireframe data to staged sync and production replication.

Overview ​

Phases ​

1. Planning ​

Wireframe includes refresh date/time, actions, copy, links, and assets.

2. Automation ​

bash
make pull
make select DATE=2026-02-03/r1
make build
make preview
1
2
3
4

3. Review ​

If corrections are needed:

bash
make edit DATE=2026-02-03 REFRESH=r1
make preview DATE=2026-02-03 REFRESH=r1
1
2

4. Deployment ​

bash
make push DATE=2026-02-03 REFRESH=r1
make done DATE=2026-02-03 REFRESH=r1
make commit DATE=2026-02-03 REFRESH=r1
make replicate
1
2
3
4

Recovery ​

If a sync introduced bad content:

  1. disable/contain in Business Manager
  2. rebuild known-good refresh
  3. re-push known-good refresh
  4. verify staging before replication
