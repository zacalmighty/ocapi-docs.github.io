Producer Workday Simulation ​

A walkthrough of a typical web producer day, with expected output at each step and what the producer is thinking. Use this to understand blocking errors, approval prompts, and the flow.

Principle: Use Make Only ​

You do not need to run node directly. All producer commands are:

bash
make <command>
1

make help shows the full list. If a developer asks you to run a Node script, ask them to expose it via make instead.

Switching Data Source ​

Producer thinking: "Ecomm gave me a Smartsheet link. I need to switch from local Excel to Smartsheet."

bash
make source SOURCE=smartsheet
1

Expected output:

  ✓ Switched to smartsheet
1

Producer thinking: "Done. Next make pull will fetch from Smartsheet. I need SMARTSHEET_API_KEY in .env — dev set that up."

Switch back to local:

bash
make source SOURCE=local
1

Switching OCAPI (SFCC Sync) ​

Producer thinking: "I need to push to SFCC. Is OCAPI on?"

bash
make config
1

Shows OCAPI: enabled or disabled.

Enable (requires .env SFCC vars):

bash
make ocapi-on
1

Disable (e.g. working offline):

bash
make ocapi-off
1

Quick Reference: Options That Make Sense ​

You want…Use
Skip confirmation prompts (CI, scripts)make push YES=1
Force rebuild after template editmake build FORCE=1
Force re-push (developer said so)make push FORCE=1
Target a specific datemake build DATE=2026-02-14
Target a specific refresh (r1, r2)make push REFRESH=r2
All refreshes in a datemake push ALL=1
Fetch Smartsheet and convertmake pull CONVERT=1
Use local Excelmake source SOURCE=local
Use Smartsheetmake source SOURCE=smartsheet
Enable SFCC syncmake ocapi-on
Disable SFCC syncmake ocapi-off
Switch brandmake switch TO=ann
