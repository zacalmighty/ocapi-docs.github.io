registry ​

Manage the asset registry for tracking current assets per zone.

What it does ​

The registry command manages the Asset Registry, which tracks the current asset ID for each zone. This enables:

  • NO_CHANGE action to reuse existing assets
  • Asset ID continuity across refreshes
  • Tracking what's currently live

When to use it ​

  • Viewing current asset assignments
  • Rebuilding registry after manual changes
  • Clearing registry to start fresh

Usage ​

bash
# Show registry via Make (default view)
make registry

# Show registry (default)
node src/cli/index.js registry <brand>

# Bootstrap from existing files
node src/cli/index.js registry <brand> --bootstrap

# Clear registry
node src/cli/index.js registry <brand> --clear

# List all IPIDs in the registry
make registry-ipids
node src/cli/index.js registry <brand> --ipids

How Registry Affects Processing ​

ActionRegistry Behavior
LAUNCHCreates new entry with new asset ID
UPDATEUses existing asset ID from registry
REMOVERemoves entry from registry
NO_CHANGEReads asset ID from registry (no processing)

Make Equivalent ​

bash
make registry                    # Show registry dashboard
1

Consolidated

make registry maps to node src/cli/index.js registry <brand> --show. Advanced operations (--bootstrap, --clear, --inspect, --diff) are available through the Node CLI.
