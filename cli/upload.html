upload ​

Upload content assets only (no campaign or slot updates).

Usage ​

bash
make upload
make upload DATE=2026-02-03
make upload DATE=2026-02-03 REFRESH=r2
1
2
3

Make Variables ​

VariableDescription
DATE=YYYY-MM-DDTarget specific refresh date
REFRESH=r#Target specific refresh ID

The make upload wrapper only forwards DATE and REFRESH.

Options ​

Variable / ARGSDescription
DATE=YYYY-MM-DDTarget specific refresh date
REFRESH=r#Target specific refresh ID
ARGS="--dry-run"Preview without uploading
YES=1 or ARGS="--yes"Skip confirmation prompt

Behavior ​

  1. Resolves refresh from DATE/REFRESH (or sticky selection).
  2. Validates refresh path and campaign ID prefix.
  3. Requires OCAPI to be enabled (make setup).
  4. Finds local assets by campaign prefix.
  5. Prompts: Upload X asset(s) to SFCC? unless --yes/--force.
  6. Uploads changed assets only.

Output Example ​

text
  • 📅 Found refresh for 2026-02-10/r1: dev-env/loft/refreshes/2026-02-10/r1/refresh.json
  • 📤 Uploading assets for: loft-2026-02-10-r1
  •    Found 5 assets
  ✔ ✅ Upload complete: 5 uploaded
