build ​

Generate HTML templates and OCAPI payload for the selected date.

Usage ​

bash
make build                       # Uses sticky date
make build DATE=2026-02-14       # Override for one command
make build DATE=2026-02-14 REFRESH=r2
make build DATE=2026-02-14 ALL=1 # Build all refreshes for date
1
2
3
4

If a date has multiple refreshes and REFRESH is omitted, build resolves in this order:

  1. sticky date/r# from dev-env/{brand}/.current-date
  2. interactive refresh picker (TTY)
  3. non-interactive prompt to pass explicit REFRESH (or ALL=1)

What It Does ​

  1. Loads refresh.json for the selected date
  2. Checks build guards (see below)
  3. Compiles Refresh DTO into Campaign domain model
  4. Generates HTML from Handlebars templates
  5. Writes ocapi-payload.json (SFCC-ready)
  6. Shows file count and next step hint

Build Guards ​

Before generating, the build command checks the current state of the date to prevent accidental overwrites.

Already Synced ​

If sync-config.json shows synced: true:

  📅 2026-02-08 (NFP 70 / FP 50%)

  ⚠  This date was already synced on 2026-02-08T14:30:00Z
     Use: make select  to pick another date
     Use: make edit    to force rebuild (rare)
1
2

5

Why: Another producer (or you) already pushed this date to SFCC. Rebuilding would overwrite their work.

Already Built ​

If ocapi-payload.json exists:

  📅 2026-02-10 (NFP 60 / FP 40%)

  ℹ  This date is already built.
     Use: make edit    to rebuild after template changes
     Use: make push    to sync to SFCC

Why: The HTML and payload are already generated. No need to regenerate unless templates changed.

Force Rebuild ​

Use make edit to bypass the build guard:

bash
make edit                        # Force-rebuild selected date
make edit DATE=2026-02-14        # Force-rebuild specific date
1
2

This is equivalent to make build --force and is intended for use after editing templates.

Related ​

  • edit — Force-rebuild (bypasses guards)
  • push — Sync the built date to SFCC
  • select — Change the working date
  • preview — Review before pushing
