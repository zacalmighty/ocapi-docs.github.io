delete ​

Delete a refresh from SFCC and local filesystem.

What it does ​

The delete command removes a refresh, including:

  • Local files (refresh.json, assets, previews)
  • SFCC content assets (if not --local-only, best effort)
  • Campaign (best effort)

When deleting by date/refresh, the command derives asset IDs from:

  • preview/templates/{assetType}/*.html
  • preview/rendered/*.html

If SFCC deletes are partial, the command reports an incomplete status with failed asset IDs.

When to use it ​

  • Cleaning up old or test refreshes
  • Removing cancelled campaigns
  • Freeing up space from historical data

Usage ​

To delete: You must pass DATE=YYYY-MM-DD. Without it, the command lists available refreshes and exits (no delete is performed).

bash
# List available refreshes (no DATE → no delete)
make delete

# Delete specific date (DATE= required)
make delete DATE=2026-02-03

# Delete specific refresh ID
make delete DATE=2026-02-03 REFRESH=r2

# Local files only (skip SFCC)
make delete DATE=2026-02-03 ARGS="--local-only"

Testing sync from scratch ​

To delete a refresh from both SFCC and dev-env, then re-sync (e.g. to test "X created, Y updated"):

  1. Delete: make delete DATE=2026-02-09 REFRESH=r1 FORCE=1 (removes from SFCC and dev-env/{brand}/refreshes/{date}/{refresh}/).
  2. Recreate: Run make pull and then make refresh DATE=... for that date (or restore the refresh from source) so the refresh folder and ocapi-payload.json exist again.
  3. Sync: make push DATE=2026-02-09 REFRESH=r1 YES=1.
