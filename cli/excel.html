excel ​

Parse Excel or Smartsheet wireframe into Refresh JSON.

Included in make pull

The fetch step is now part of make pull, which combines git sync + data fetch + status dashboard in one command. You don't need to call fetch separately. See pull.

What it does ​

The excel command parses wireframe data from Excel files or Smartsheet and transforms it into structured Refresh DTOs. This is the data ingestion step in the campaign workflow.

When to use it ​

  • As part of make pull (automatic)
  • Standalone: re-fetching data without git sync
  • Testing with a specific local Excel file

Usage ​

bash
# Use configured source
make excel

# Specify Excel file path
make excel FILE=docs/excel/LOFT.xlsx

# With options (CI / non-interactive)
make excel ARGS="--mode=auto --persist"

Arguments ​

ArgumentRequiredDescription
brandYesBrand key (loft, ann)
targetNoPath to Excel file (uses configured source if omitted)

Flags ​

FlagDefaultDescription
--mode=<mode>autoParser mode (auto, converted, banner, flat)
--sheet=<name>-Specific sheet name to parse
--forcefalseForce regeneration even if data exists
--persistfalseSave parsed data to filesystem

Parser Modes ​

ModeDescription
autoAuto-detect format based on sheet structure
convertedLOFT (Converted) style with parent/child rows
bannerBanner-style headers with date columns
flatFlat rows with DATE + TIME columns

Excel Format Compatibility ​

Both "Converted" and "Changeouts" Excel formats are fully supported. The parser normalizes differences at parse time so both produce identical data structures:

ConceptConverted FormatChangeouts FormatCanonical
Popup disclaimersPOPUPDISCLAIMER→ POPUP
Coupon copyCOUPONSHTML COPY→ COUPONS
PLP headerPLP_HEADERHEADER→ PLP_HEADER
Promo banner linesPPH (3 items)PPH-A, PPH-B, PPH-C→ PPH (consolidated)
No-change actionNO_CHANGENO CHANGE/LINK SAME→ NO_CHANGE
DeviceBOTHRESPONSIVE D & M→ BOTH
Site locationPOPUPPOP UP→ POPUP
Item orderExplicit numbersAuto-assigned if missingSequential 1, 2, 3...
